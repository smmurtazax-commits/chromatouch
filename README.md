# ChromaTouch Android Project

This folder is a ready-to-build Android Studio project wrapping the ChromaTouch finger color app in a full-screen WebView.

## Build the APK
1. Open this `ChromaTouchAndroid` folder in **Android Studio**.
2. Wait for Gradle sync to finish.
3. Click **Build > Build Bundle(s) / APK(s) > Build APK(s)** in the menu bar.
4. When the build finishes, click **locate** in the notification to get your `app-debug.apk` file.
